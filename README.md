# Kavtaut

> API Client for Experimentalist!

Kavtaut (કવટાઉત) is named after Jesaji (જેસાજી) of the famous Jesaji-Vejaji (જેસાજી-વેજાજી) duo, as referenced in Gujarati folk traditions, including Duha and Charani literature. Jesaji is traditionally referred to as Kavtaut, meaning the son of Kavtautji (કવટાઉતજીના પુત્ર).
